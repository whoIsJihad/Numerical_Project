but the current suite does not test them. The plot test checks file creation,
not visual correctness. Synthetic data is generated by the same current solver,
so those tests are not an independent reference for every numerical method.

## Verified baseline

Commands run from the project root using the existing virtual environment:

```bash
.venv/bin/python -m pytest -ra
.venv/bin/python run.py
```

The runner uses the 26 RTC measurements, temperature 306.15 K, `ns=1`,
`root_method="hybrid"` and `fit_method="lm"`.

| Output | Observed value |
| --- | --- |
| Converged | `True` |
| Reason | `error stopped improving` |
| RMSE | `0.0009064221528746219 A` |
| Iph | approximately `0.761354638 A` |
| I0 | approximately `3.77999444e-7 A` |
| Rs | approximately `0.0355425461 ohm` |
| Rsh | approximately `50.0000009 ohm` |
| n | approximately `1.49732101` |

The stopping flag describes the optimizer's stopping rule. It does not establish
parameter recovery or uniqueness. In particular, Rsh remains near its initial
value of 50; sensitivity and scaling need investigation before interpreting it.
